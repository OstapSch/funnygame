# МИША НЕ МОЖЕТ УЧИТЬСЯ

Браузерная 3D-игра на three.js: симулятор-менеджер внимания от первого лица.
У Миши шесть минут на подготовку к AS Level и девять привычек, которые его отвлекают.

## Запуск

- **Двойной клик по `index.html`**: игра работает без сервера и без интернета.
- **Через Flask** (нужен для загрузки моделей из `models/`):
  - Windows — `start.bat`;
  - macOS — `start.command`;
  - вручную — `pip install flask` и `python app.py`.

  Браузер откроется сам на http://127.0.0.1:5000.

## Управление

| Клавиша | Что делает |
|---|---|
| мышь | клики по экрану ноутбука и телефона |
| 1–8, Пробел | сбросить привычку (клавиша подписана под её шкалой) |
| Пробел | во время отжиманий — отжимание |
| Tab | взять или положить телефон |
| Esc | пауза |
| M | звук |
| ~ | debug: значения, FPS, принудительный запуск привычек, симуляция баланса (B) |

## Как устроено

- `index.html` — вся игра. Порядок частей внутри: three.min.js → встроенные GLTFLoader и RoundedBoxGeometry → игра.
- Баланс — объект `CONFIG` в начале скрипта игры.
- `models/` — необязательные `.glb`. Имена файлов и габариты — в константах `SLOT_*`.
- `app.py` — маленький Flask-сервер. Отдаёт игру и список моделей.
