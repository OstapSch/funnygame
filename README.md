# МИША НЕ МОЖЕТ УЧИТЬСЯ

Браузерная 3D-игра на three.js: симулятор-менеджер внимания от первого лица.
У Миши шесть минут на подготовку к AS Level и девять привычек, которые его отвлекают.

Привычки копятся на шкалах по бокам экрана, сбрасывать их надо самому, клавишей под шкалой.
Если шкала дошла до 100%, у тебя есть 6 секунд, чтобы нажать её клавишу. Не успел — Миша проиграл, и у каждой привычки своя концовка.
Пока Миша занят другим делом, отсчёт стоит на паузе.

## Запуск

- **Двойной клик по `index.html`**: игра работает без сервера и без интернета.
- **Через Flask** (нужен для загрузки моделей из `models/`):
  - Windows — `start.bat`;
  - macOS — `start.command`;
  - вручную — `pip install flask` и `python app.py`.

  Браузер откроется сам на http://127.0.0.1:5000.

## На телефоне

Игра идёт на телефоне горизонтально. Шкалы по бокам — это кнопки: тапни шкалу, чтобы сбросить привычку. Пауза — кнопка ❚❚ слева внизу. Отжимания делаются тапами по экрану.

Как открыть игру на телефоне:
- **По ссылке на claude.ai:** https://claude.ai/artifact/TizozPwNAKaBVZADSqSKN2 — открывается в приложении Claude или в браузере под тем же аккаунтом. Ссылка приватная: другим людям доступ даётся через меню «Поделиться» на странице.
- **С компьютера по Wi-Fi.** Запусти `start.bat` или `start.command`. Сервер напишет адрес «С телефона (тот же Wi-Fi)» — открой его на телефоне, подключённом к той же сети. Если не открывается, разреши Python входящие подключения в брандмауэре.

## Управление

| Клавиша | Что делает |
|---|---|
| мышь | клики по экрану ноутбука и телефона |
| 1–8, Пробел | сбросить привычку (клавиша подписана под её шкалой) |
| Пробел | во время отжиманий — отжимание |
| Tab | взять или положить телефон |
| Esc | пауза |
| M | звук |
| ~ | debug: значения, FPS, принудительный запуск привычек, симуляция баланса (B) |

## Как устроено

- `index.html` — вся игра. Порядок частей внутри: three.min.js → встроенные GLTFLoader и RoundedBoxGeometry → игра.
- Баланс — объект `CONFIG` в начале скрипта игры. Главные ручки:
  - `CRIT_GRACE` — секунды на спасение полной шкалы, 0 — проигрыш сразу;
  - `FILL_SCALE` — скорость, с которой копятся привычки;
  - `CORRECT_PROGRESS` — прогресс за верный ответ.
- `models/` — необязательные `.glb`. Имена файлов и габариты — в константах `SLOT_*`.
- `app.py` — маленький Flask-сервер. Отдаёт игру и список моделей.
